คู่มือสรุป Struts 2 Framework

รวม Concept โครงสร้างการทำงาน และคำสั่งที่สำคัญทั้งหมดใน Struts 2 สำหรับการพัฒนา Web Application ด้วย Java

1. Core Concepts (แนวคิดหลัก)

MVC Pattern

Struts 2 ออกแบบมาโดยใช้สถาปัตยกรรม MVC (Model-View-Controller) เพื่อแยกส่วนการแสดงผล (View) และการประมวลผล (Controller) ออกจากกัน

  • Model: ส่วนจัดการข้อมูลและ Business Logic
  • View: ส่วนแสดงผล (JSP)
  • Controller: ส่วนควบคุม (Action Classes)

Interceptors

เปรียบเสมือน Middleware ที่คอยดักจับและประมวลผล Request ก่อนที่จะส่งไปถึง Action เช่น การตรวจสอบสิทธิ์ (Authentication), การจัดการไฟล์อัปโหลด หรือการดึงข้อมูลเข้าสู่ ValueStack

ValueStack & OGNL

ValueStack: พื้นที่จัดเก็บข้อมูลชั่วคราวระหว่างที่ Action ทำงาน เพื่อให้ View สามารถดึงไปแสดงผลได้

OGNL: (Object-Graph Navigation Language) ภาษานิพจน์ที่ใช้สำหรับดึงข้อมูลจาก ValueStack ไปแสดงที่หน้า UI อย่างง่ายดาย

Result & Result Types

เมื่อ Action ทำงานเสร็จสิ้น จะทำการ Return ค่า String ออกมา (เช่น "success", "error") เพื่อบอกให้ Struts ทราบว่าจะต้องส่งต่อไปที่ View หน้าใด

2. Configuration (การตั้งค่า)

struts.xml (ไฟล์ตั้งค่าหลัก)

ไฟล์นี้ใช้สำหรับกำหนดค่า Routing ระหว่าง URL, Action, และ View (JSP)

<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE struts PUBLIC 
    "-//Apache Software Foundation//DTD Struts Configuration 2.5//EN" 
    "http://struts.apache.org/dtds/struts-2.5.dtd">

<struts>
    <!-- กำหนดแพ็กเกจหลัก -->
    <package name="default" extends="struts-default">
        
        <!-- กำหนด Action -->
        <action name="hello" class="com.example.HelloAction" method="execute">
            <!-- ถ้า return "success" จะไปที่ hello.jsp -->
            <result name="success">/hello.jsp</result>
            <!-- ถ้า return "error" จะไปที่ error.jsp -->
            <result name="error">/error.jsp</result>
        </action>

    </package>
</struts>

3. Actions (คอนโทรลเลอร์)

การสร้าง Action Class

Action คือคลาสที่ทำหน้าที่ประมวลผล Request มักจะสืบทอดมาจาก ActionSupport

package com.example;

import com.opensymphony.xwork2.ActionSupport;

public class UserAction extends ActionSupport {
    
    // ตัวแปรที่จะถูกส่งไปหน้า JSP (ต้องมี Getter/Setter)
    private String username;

    // Method หลักที่ทำงาน
    @Override
    public String execute() throws Exception {
        if ("admin".equals(username)) {
            return SUCCESS; // ค่าคงที่ "success"
        }
        return ERROR; // ค่าคงที่ "error"
    }

    // Getters and Setters
    public String getUsername() { return username; }
    public void setUsername(String username) { this.username = username; }
}

Annotation-based Config (@Action)

ใน Struts 2 รุ่นใหม่ๆ เราสามารถใช้ Annotations แทนการเขียน struts.xml ได้เลย

import org.apache.struts2.convention.annotation.Action;
import org.apache.struts2.convention.annotation.Result;
import com.opensymphony.xwork2.ActionSupport;

public class LoginAction extends ActionSupport {
    
    @Action(value = "/login", results = {
        @Result(name = "success", location = "/welcome.jsp"),
        @Result(name = "input", location = "/login.jsp")
    })
    public String execute() {
        return SUCCESS;
    }
}

4. Struts 2 UI & Data Tags (คำสั่งแท็กที่หน้าจอ)

ต้องทำการ import taglib ก่อนใช้งานในหน้า JSP เสมอ:
<%@ taglib prefix="s" uri="/struts-tags" %>

UI Tags (สร้างฟอร์ม)

แท็กสำหรับสร้าง HTML Forms ซึ่งจะเชื่อมโยงข้อมูลกับ Action อัตโนมัติ

<!-- สร้างแบบฟอร์ม ส่งข้อมูลไปที่ action='login' -->
<s:form action="login">
    <!-- ช่องกรอกข้อมูล (เชื่อมตัวแปร username) -->
    <s:textfield name="username" label="ชื่อผู้ใช้" />
    
    <!-- ช่องกรอกรหัสผ่าน -->
    <s:password name="password" label="รหัสผ่าน" />
    
    <!-- ปุ่ม Submit -->
    <s:submit value="เข้าสู่ระบบ" />
</s:form>

Data Tags (จัดการข้อมูล)

แท็กสำหรับแสดงค่า หรือกำหนดค่าข้อมูลจาก ValueStack

<!-- แสดงค่าตัวแปร (Output) -->
ยินดีต้อนรับ: <s:property value="username" />

<!-- การกำหนดค่าตัวแปร (Set variable) -->
<s:set var="myRole" value="role" />
Role ของคุณคือ: <s:property value="#myRole" />

Control Tags (ควบคุมทิศทาง)

แท็กสำหรับทำเงื่อนไข (If-Else) และการวนลูป (Loop)

<!-- เงื่อนไข If-Else -->
<s:if test="age >= 18">
    <p>ผู้ใหญ่</p>
</s:if>
<s:elseif test="age >= 13">
    <p>วัยรุ่น</p>
</s:elseif>
<s:else>
    <p>เด็ก</p>
</s:else>

<!-- การวนลูป (Iterator) -->
<ul>
<s:iterator value="userList" var="user">
    <li><s:property value="#user.name" /></li>
</s:iterator>
</ul>

5. OGNL (Object-Graph Navigation Language)

ตัวอย่างการอ้างอิงข้อมูลด้วย OGNL

คำสั่ง OGNL ความหมาย / การทำงาน
value="name" ดึงค่า property name จาก ValueStack (จาก Action)
value="#session['user']" ดึงค่า object ชื่อ user จาก session
value="#parameters['id']" ดึงค่าพารามิเตอร์ id ที่ส่งมาจาก URL Query String
value="#request['msg']" ดึงค่า msg จาก request scope
value="user.address.city" เข้าถึง property แบบซ้อนกัน (Chained Property)
