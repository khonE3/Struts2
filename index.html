Actions & Configuration

Action คือหัวใจหลักของ Struts2 (Controller) ที่จะถูกเรียกใช้เมื่อมี Request เข้ามา สามารถ Config ได้ 2 แบบคือ XML และ Annotation

1. XML Configuration (struts.xml)

ตั้งค่าผ่านไฟล์ struts.xml ในโฟลเดอร์ src/main/resources

xml 
<struts>
    <package name="default" namespace="/" extends="struts-default">
        <action name="login" class="com.example.LoginAction">
            <result name="success">/welcome.jsp</result>
            <result name="error">/login.jsp</result>
        </action>
    </package>
</struts>

2. Annotation Configuration (Java)

ใช้ Convention Plugin ทำให้ไม่ต้องเขียน XML (Zero Configuration)

java 
import org.apache.struts2.convention.annotation.Action;
import org.apache.struts2.convention.annotation.Result;
import com.opensymphony.xwork2.ActionSupport;

@Action(value = "/login", results = {
    @Result(name = "success", location = "/welcome.jsp"),
    @Result(name = "error", location = "/login.jsp")
})
public class LoginAction extends ActionSupport {
    private String username;
    
    public String execute() {
        if ("admin".equals(username)) return SUCCESS;
        return ERROR;
    }
    // getters and setters
}

ValueStack & OGNL

ValueStack คือพื้นที่เก็บข้อมูลหลักขณะ Request ทำงาน ส่วน OGNL (Object-Graph Navigation Language) คือภาษาที่ใช้อ่าน/เขียนข้อมูลใน JSP

OGNL Syntax Basics

Syntax คำอธิบาย ตัวอย่าง
property เข้าถึง Property บน ValueStack โดยตรง (ไม่มี #) <s:property value="username" />
#scope.key เข้าถึงข้อมูลใน Context Map (เช่น Session, Request) <s:property value="#session.user" />
%{exp} บังคับให้ประมวลผล Expression ใน Attribute <s:textfield name="id" value="%{userId}" />
@class@method เรียกใช้ Static Method หรือตัวแปร <s:property value="@java.lang.Math@PI" />
📦

Context Scopes

การจัดการข้อมูลในระดับ Request, Session และ Application

Accessing Scopes via Aware Interfaces (Java)

วิธีที่ดีที่สุดคือการ implement *Aware interfaces เพื่อให้ Struts2 inject map เข้ามาให้

java 
public class UserAction extends ActionSupport implements SessionAware {
    private Map<String, Object> session;

    @Override
    public void setSession(Map<String, Object> session) {
        this.session = session;
    }

    public String execute() {
        // บันทึกข้อมูลลง Session
        session.put("loggedInUser", "John Doe");
        return SUCCESS;
    }
}

UI Tags (s:form)

ต้องประกาศ <%@ taglib prefix="s" uri="/struts-tags" %> ที่หัวไฟล์ JSP เสมอ

Form Elements (JSP)

jsp 
<s:form action="saveUser">
    <!-- Text Field ผูกกับตัวแปร username -->
    <s:textfield name="username" label="Username" />
    
    <!-- Password Field -->
    <s:password name="password" label="Password" />
    
    <!-- Dropdown (Select) -->
    <s:select name="country" label="Country" 
              list="{'Thailand', 'USA', 'Japan'}" />
              
    <!-- Radio Buttons -->
    <s:radio name="gender" label="Gender" 
             list="#{'M':'Male', 'F':'Female'}" />
             
    <!-- Submit Button -->
    <s:submit value="Register" />
</s:form>

Control Tags (s:iterator)

Looping over a List (JSP)

ใช้สำหรับวนลูป List, Set, Map หรือ Array

jsp 
<!-- วนลูป Object ในตัวแปร 'users' -->
<s:iterator value="users" var="user" status="stat">
    <div class="row">
        No. <s:property value="#stat.index + 1" />
        Name: <s:property value="#user.firstName" />
        <!-- ตรวจสอบว่าเป็นแถวคู่หรือคี่ -->
        <s:if test="#stat.even">(Even Row)</s:if>
    </div>
</s:iterator>

Interceptors

Interceptor คือโมดูลที่ทำงานคั่นก่อน/หลัง Action (เทียบเท่า Filter) ใช้ทำระบบ Security, Logging, Validation ฯลฯ

Custom Interceptor (Java)

java 
public class AuthInterceptor extends AbstractInterceptor {
    @Override
    public String intercept(ActionInvocation invocation) throws Exception {
        Map<String, Object> session = invocation.getInvocationContext().getSession();
        
        // เช็คว่า Login หรือยัง
        if (session.get("user") == null) {
            return "login"; // ส่งกลับหน้า Login
        }
        
        // ทำงาน Action ต่อไป
        return invocation.invoke(); 
    }
}

Configuring Interceptor Stack (struts.xml)

xml 
<interceptors>
    <interceptor name="auth" class="com.example.AuthInterceptor"/>
    <interceptor-stack name="secureStack">
        <interceptor-ref name="defaultStack"/>
        <interceptor-ref name="auth"/>
    </interceptor-stack>
</interceptors>

<action name="dashboard" class="com.example.DashboardAction">
    <interceptor-ref name="secureStack"/>
    <result name="success">/dashboard.jsp</result>
</action>

Validation Framework

XML Validation (ActionName-validation.xml)

สร้างไฟล์ชื่อเดียวกับ Action ตามด้วย -validation.xml ในโฟลเดอร์เดียวกัน

xml 
<!DOCTYPE validators PUBLIC "-//Apache Struts//XWork Validator 1.0.2//EN" "http://struts.apache.org/dtds/xwork-validator-1.0.2.dtd">
<validators>
    <field name="username">
        <field-validator type="requiredstring">
            <message>Username is required.</message>
        </field-validator>
    </field>
    <field name="age">
        <field-validator type="int">
            <param name="min">18</param>
            <param name="max">100</param>
            <message>Age must be between 18 and 100.</message>
        </field-validator>
    </field>
</validators>

File Upload / Download

File Upload Action (Java)

Form ใน JSP ต้องใส่ enctype="multipart/form-data"

java 
public class UploadAction extends ActionSupport {
    private File myFile;                 // ไฟล์
    private String myFileContentType;    // ชนิดไฟล์
    private String myFileFileName;       // ชื่อไฟล์
    
    // getters & setters สำหรับ 3 ตัวแปรด้านบน
    
    public String execute() throws Exception {
        File destFile = new File("C:/uploads/", myFileFileName);
        FileUtils.copyFile(myFile, destFile); // copy จาก temp
        return SUCCESS;
    }
}

File Download Config (struts.xml)

xml 
<action name="download" class="com.example.DownloadAction">
    <result name="success" type="stream">
        <param name="contentType">application/octet-stream</param>
        <param name="inputName">inputStream</param> <!-- property ใน Action -->
        <param name="contentDisposition">attachment;filename="report.pdf"</param>
        <param name="bufferSize">1024</param>
    </result>
</action>
